Your repository is:

samansum3.github.io repository

Your live website (if Pages is enabled) is:

https://samansum3.github.io

To manage it:

Go to the repository above.

Clone it locally if you haven't already:

git clone https://github.com/samansum3/samansum3.github.io.git
cd samansum3.github.io
Edit your HTML/CSS/JS (or Jekyll files if you use Jekyll).

Commit and push:

git add .
git commit -m "Update website"
git push
GitHub Pages will automatically rebuild and publish the site after you push.

If you forgot where the GitHub Pages settings are:

Open the repository.
Click Settings.
In the left sidebar, click Pages.
There you can see:
Which branch is being published (usually main)
The deployment status
The live site URL
